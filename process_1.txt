  ① 云端/APP 触发OTA
         │
         ▼
  ② ESP32 连接服务器，HTTP GET 下载固件
         │
         ▼
  ③ ESP32 分包(每包256B)通过UART发给STM32
         │
         ▼
  ④ STM32 接收数据，逐包写入 W25Q64「下载区」
         │
         ▼
  ⑤ 全部接收完毕，STM32 校验 W25Q64 中固件的CRC32
         │
    ┌────┴────┐
    │ 校验OK?  │
    └────┬────┘
  Yes    │    No → 通知ESP32重传
    ┌────┴──────────────────┐
    │ 把当前APP备份到W25Q64  │  (可选，实现回退)
    │ 「备份区」             │
    └────┬──────────────────┘
         │
         ▼
  ⑥ 写入OTA标志到STM32内部Flash参数区
         │
         ▼
  ⑦ STM32 软复位，进入Bootloader
         │
         ▼
  ⑧ Bootloader 从 W25Q64 读取新固件
         │
         ▼
  ⑨ 擦除APP区 → 逐页写入 → CRC校验
         │
    ┌────┴────┐
    │ 校验OK?  │
    └────┬────┘
  Yes    │    No → 从「备份区」恢复旧固件
         ▼
  ⑩ 清除OTA标志，跳转APP运行
